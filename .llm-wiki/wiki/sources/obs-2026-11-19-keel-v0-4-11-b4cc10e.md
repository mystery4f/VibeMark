# ⭐ Observation: keel 参考版本锚定 v0.4.11 / b4cc10e，可逐字节重建

VibeMark 项目依赖的 keel 参考副本锚定在 tag v0.4.11（提交 b4cc10e9c32ae1c900f2aade39ca7041a872d698，2026-11-17，fix(android): preserve keyboard requests until window focus is ready）。本地浅克隆位于仓库内 .tmp/keel-repo（24M，含 ui/kit/code_editor*.go 等实现源码，docs 下 63 个文件，中文文档在同目录 *.zh-CN.md，code_editor 文档在 docs/kit/ 下而非 docs/ 顶层）。删掉后可用 `git -c http.proxy= -c https.proxy= clone --depth 1 --branch v0.4.11 https://github.com/dyike/keel <dir>` 逐字节还原；若改为 clone main 则版本漂移，读到的 API 可能已变。配套：dyike/keel issue 总数 0，搜 "keel" 会被 keel-hq/keel（Kubernetes 工具）淹没，唯一权威来源是仓库自身。
